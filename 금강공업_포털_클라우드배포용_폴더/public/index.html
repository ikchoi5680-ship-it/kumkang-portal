거래처 PC 앱 배포 및 설치 방법

거래처에 무거운 프로그램을 설치하게 할 필요 없이, 웹 앱(PWA) 기술을 사용하면 거래처 PC 바탕화면에 아이콘을 만들고 독립 앱처럼 구동할 수 있습니다.

📌 거래처 사용 가이드:
  1. 크롬(Chrome) 또는 엣지(Edge) 브라우저로 본 웹 주소 접속
  2. 브라우저 우측 상단 주소창의 [앱 설치 아이콘 ⊕] 클릭
  3. 바탕화면에 '금강공업 시험성적의뢰' 아이콘 생성 완료
  4. 더블클릭하면 인터넷 창이 아닌 독립된 전용 프로그램처럼 실행됩니다!

✨ 장점: 프로그램 업데이트 시 거래처가 재설치할 필요 없이 자동으로 최신 버전이 반영됩니다.
