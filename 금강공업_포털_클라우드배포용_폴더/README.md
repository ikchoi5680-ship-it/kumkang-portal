# 금강공업 시험성적의뢰 및 실시간 진행현황 추적 포털 (정식 운영 버전)

금강공업(주)의 공식 시험성적의뢰서(KHOPC-06F04) 양식을 전산화하여, 거래처에서 온라인으로 손쉽게 성적서를 의뢰하고 실시간 진행 상태(접수 ➔ 진행중 ➔ 발송완료)를 확인 및 공인 성적서를 즉시 다운로드할 수 있는 웹/PWA 시스템입니다.

---

## 📌 주요 핵심 기능

1. **거래처 전용 포털**
   - **거래처별 독립 계정**: 거래처코드와 비밀번호로 로그인하여 본인 거래처의 의뢰 내역만 안전하게 열람/관리
   - **공식 A4 서식 작성**: 종이 시험성적의뢰서 서식(KHOPC-06F04) 그대로 품목, 규격, 수량, LOT 정보를 직관적으로 입력
   - **실시간 4단계 프로세스 추적**: `1. 신청/대기` ➔ `2. 접수완료` ➔ `3. 시험진행중` ➔ `4. 발송완료`
   - **공인 시험성적서 즉시 다운로드**: 품질팀이 최종 승인 및 발송한 실제 PDF 성적서를 원클릭 다운로드

2. **품질관리팀 관리자 콘솔**
   - **전체 의뢰 현황 대시보드**: 거래처별/기간별 검색, 상태 필터링, 실시간 KPI 카운터
   - **원클릭 승인 & 디지털 인영 날인**: 접수 승인 시 승인권자(예: 하지현 팀장)의 공인 전자 인영이 의뢰서에 자동 날인
   - **실제 성적서 PDF 첨부 및 발송**: 발송 완료 시 발행된 시험성적서 PDF 파일을 첨부하여 거래처로 즉시 배포
   - **사용자 및 권한 관리 (RBAC)**: 사내 임직원 및 거래처의 역할(최고 관리자, 시험 실무자, 영업, 거래처) 부여 및 통제

3. **거래처 PC 앱 (PWA) 지원**
   - 거래처 PC에 무거운 프로그램을 설치하지 않고도, 브라우저 메뉴에서 **[앱으로 설치]** 클릭 시 바탕화면에 전용 아이콘 생성
   - 인터넷 창이 아닌 단독 윈도우 애플리케이션처럼 구동

## 🚀 실행 및 운영 방법

### 1. 로컬 및 사내 PC에서 바로 실행하기
* 폴더 안에 있는 **`start.bat`** 파일을 마우스로 **더블클릭**합니다.
* 자동으로 서버가 실행되고, 웹 브라우저가 열리며 [http://localhost:3000](http://localhost:3000) 로그인 화면이 표시됩니다.

### 2. 거래처 및 사내 다른 PC에서 접속하게 하기 (네트워크 공유)
1. 서버가 켜진 PC의 사내 IP 주소(예: `192.168.0.50`)를 확인합니다.
2. 거래처나 사내 다른 컴퓨터의 인터넷 브라우저 주소창에 `http://192.168.0.50:3000` 을 입력하면 바로 접속됩니다.
3. 거래처 PC에서 브라우저 주소창 우측의 **[앱 설치 ⊕]**를 누르면 바탕화면에 전용 바로가기 아이콘이 생성됩니다.
